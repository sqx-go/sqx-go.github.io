About

SQL for the data you already have.

sqx is a free, open-source command-line tool that lets you query CSV files, JSON, logs and live websites with SQL. It ships as one small binary with nothing else to install, so it works the same on a laptop, a server or a CI runner.

Why sqx exists

Most data questions start small: which customers are on the pro plan, which of these links are broken, does this domain have a DMARC record. Answering them usually means opening a spreadsheet, writing a throwaway script or loading files into a database server. sqx makes the answer one line of SQL in the terminal you already have open.

How sqx is made

sqx is written in Go and embeds a pure-Go build of SQLite, so it compiles to a single static binary for macOS, Linux, Windows and FreeBSD without a C toolchain. Everything runs on your own machine: your files are never uploaded anywhere, and web requests go straight from your computer to the sites you query, through a cache you control.
